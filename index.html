Configurar OSAIA AI

Esta página funciona sin servidor para herramientas locales. Para recibir respuestas de un modelo de IA, necesitás un backend propio y seguro que acepte POST con { "messages": [...] } y responda { "reply": "..." }.

La URL se guarda únicamente en este navegador. El servidor debe permitir CORS desde este sitio. La conexión se probará al enviar el primer mensaje.

Seguridad: no pegues claves API, contraseñas ni tokens en la URL ni en el chat. Las credenciales del proveedor deben mantenerse exclusivamente en el servidor. Al conectar un backend, tus mensajes se enviarán a ese servidor.
